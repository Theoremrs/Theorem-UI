ORIGINAL ARTIFACT
Sample artifact · Esc to return

A cabinet of representations.

This is a standalone HTML design study of a Ratatui/Ratzilla-led artifact cabinet. It is not the production Rust/WASM implementation and is not connected to Theorem.

Try it: switch Expressive / Calm, change the complete palette, choose a preview override, search or filter the cards, expand the cabinet, and open any artifact. The maze demo can be played with the arrow keys.

Expressive defaults to pixel interpretations. Calm defaults to original previews. An explicit preview preference survives theme changes. Original artwork is not recolored; the pixel representations and terminal chrome adapt together.

The six artifacts are purpose-made samples. Their labels, revisions, and descriptions are illustrative, not retrieved project data.
