# Theo Web Terminal Workbench

Start with [START-HERE.md](START-HERE.md).

A web-only implementation specification incorporating Herdr layout reuse and Core-backed terminal continuity, ELY component ports, Codex interaction/code reuse, selected OpenIDEA capabilities, local RustyRed, modular panels, and Theia retirement. Native Theo and Platinum are deferred.

**48 requirements · 62 acceptance cases · evidence is recorded per case; live-only gates remain explicit.**
